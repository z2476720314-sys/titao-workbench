# 透明图案摆放与多角度评审

目标：沿用原图画布、比例、透明度和模板外部变换，让自动微调利用透明留白避让镜头，检查多个成品角度。

- [x] 回归：透明边距允许下移；可见内容不能越界；连续背景保持满铺；评审收到多个独立清晰角度。
- [x] 实现：Normalize 输出可见内容边界；自动摆放将该边界传到 PhotoCraft 和 Photoshop；评审允许必要下移、缩小与截边贴底。
- [x] 验证：Go 测试、vet、Windows 构建；六款真实素材输出到独立验证目录，检查脸、文字、壳底和原文件完整性。
- [x] 审查：独立代码审查，处理实质问题；更新版本与 changelog，交付可执行文件。

约束：不修改输入素材、模板、原始成品及 images；28 号蓝色色块不属于摆放修复；不改 UI，不新增依赖，不发布远端。

用户最终明确：只允许透明/空白留边超出壳底，可见内容不能越过壳面边界。正式配置保留 no_crop=true；下移余量不足时适度等比缩小，不能裁掉底部实际内容。

补充：图案明显直线截断边必须贴对应壳边，缩放后保留锚点；自然弧形不强制贴边。左右均明显时保持满宽；纵向取更明显的边，相等时贴底。

验证结果：Go测试通过，vet和Svelte静态检查通过；当前代码PhotoCraft固定参数几何验证6款42张。自动模型复测6款42张，其中4款保留人工复核。原始91文件哈希未变。Photoshop未做真实渲染。
