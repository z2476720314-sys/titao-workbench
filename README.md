# 套图工作台

把抠好的透明图案套进 PS 分层 TIF 模板的智能对象，按模板自带分割线（默认每 800px 一格）切出每张手机壳 JPG。

- 模板与图案都只读，程序永远复制到临时目录再动
- 摆放大小由视觉模型判断（不需要人工调档）
- 单文件 exe，不依赖 Python 或环境变量

## 用法

双击 `build/bin/套图工作台.exe`。侧栏五个页签：

| 页签 | 作用 |
|---|---|
| 套图 | 选图案与模板、调摆放参数、开始套图 |
| 任务队列 | 每个「图案 × 模板」组合的实时进度与耗时 |
| 成品 | 浏览输出目录里的成品，可打开所在文件夹 |
| 设置 | 视觉模型、默认路径、默认套图参数 |
| 关于 | 版本、配置文件位置、输出目录 |

### 套图页

- **图案**：透明 PNG / JPG / TIF / WEBP，可多选文件或直接选目录（只取一层）
- **套图模板**：PS 分层 TIF，可多选或选目录。「探查结构」可先看模板里有几个智能对象、分割线间距
- **图层组**：默认「插画」，只替换该顶层组里的智能对象，底图与背景不动
- **摆放方式**：
  - `auto`（推荐）画布 1:1 —— 图案按原始像素置入，1.0 倍即刚好铺满壳面
  - `contain` 完整放下 / `cover` 铺满裁切 / `stretch` 拉伸 / `none` 原始像素
- **视觉模型自动判断图案大小**：勾上后按候选倍数各渲染一遍，交模型挑最合适的一档；不勾则用第一档固定值
- **手动档位**：逗号分隔，留空用配置里的候选
- **水平/垂直微调**：占画布宽/高的比例，`0.1` = 右移 10%
- **格边长**：默认 800，与模板分割线一致
- **裁掉图案四周透明留白**：默认开，让图案真正居中且尺寸准确

### 输出结构

```
<输出目录>/<图案名>/<图案名>_<模板名>_NN.jpg
```

默认输出目录 `E:\套图输出`。同一图案套多个模板时，成品都在同一个图案名目录下，靠文件名区分模板。

## 配置文件

`config.json` 与 exe 同目录，首次运行自动生成。设置页可直接改并保存，也可点「打开配置文件」手改。

```jsonc
{
  "base_url": "https://www.acctoken.com/v1",  // 视觉模型接口
  "api_key": "sk-...",                        // 必填，否则跳过模型判断
  "model": "deepseek-v4.1-flash",             // 需支持看图
  "max_tokens": 4000,
  "timeout_seconds": 180,
  "temperature": 0.1,
  "image_max_side": 640,                      // 送模型的预览图最长边
  "thinking": false,                          // 关掉，否则 token 被思考链烧光
  "candidates": [0.85, 0.95, 1.05, 1.15, 1.3],
  "template_dir": "E:\\套图模板",
  "pattern_dir": "E:\\插画",
  "output_dir": "E:\\套图输出",
  "group": "插画",
  "fit": "auto",
  "cell_size": 800,
  "jpg_quality": 95,
  "trim_alpha": true,
  "offset_x": 0,
  "offset_y": 0
}
```

### candidates 怎么定

`t` 是相对「刚好铺满」的倍数：`1.0` = 图案至少一个方向顶到壳边，`<1` 留白，`>1` 超出被裁切。

区间必须覆盖「明显偏小 → 明显超出」。实测：把候选换成 `[0.3,0.45,0.6,0.75]` 模型会选 `0.6`，换成 `[0.75,1.0,1.25,1.5]` 会选 `1.25` —— 它只在组内做相对比较，区间一窄选出的 t 就漂移。

## 核心机制

1. **图案规范化**（`internal/imgutil`）：始终经 Go 重存 PNG。原始 PNG 若带 300dpi 元数据，PS 会按物理尺寸换算导致图案缩小 4 倍 —— 重存一次就没这问题。可选裁掉 alpha bbox 外的透明留白。
2. **模板复制**：模板先复制进临时目录再打开，原文件只读不写。
3. **智能对象替换**（`internal/psx`）：进 SO 内部编辑，把图案按档位缩放置入内部文档（945×1890 画布），保留外层变换。同一 PSB 被多个格子共享时只替换一次，所有格子一起更新。
4. **候选渲染**：一次 PS 会话里按各档各导一张整幅拼合图。
5. **视觉模型选档**（`internal/judge`）：只送第一格（整条长图缩到 640 后每格只剩约 107px，模型看不清会判断趋同）。结论可能只在 `reasoning_content` 里，两处一起找。
6. **切格导出**：按 `cell_size` 纵向切分，逐格写 JPG。

## 开发

```bash
wails dev          # 热重载
wails build        # 产物 build/bin/套图工作台.exe
go test ./...      # 单元测试
go vet ./...       # 静态检查
```

`cmd/probe` 是端到端探针：不经 GUI 直接驱动引擎跑一次真实套图，路径硬编码在源码里（避免 shell 传参破坏西里尔文/中文路径）。

## 已知限制

- 视觉模型接口偶发超时，此时回退到候选组里中间偏小的一档（宁可略小也不裁坏），日志会标 `视觉模型判断失败`
- 目录选择只展开一层，不递归
- 需要 Photoshop 已安装并可被 COM 调用；PS 若弹出模态对话框，COM 调用会挂起
